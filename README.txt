HOW TO PUT THIS SITE ON VERCEL (about 5 minutes, free)

Option A - Drag and drop with GitHub (easiest)
1. Go to github.com and sign in (or sign up with somayvaidh08@gmail.com).
2. Click "+" (top right) > "New repository". Name it: portfolio. Set it to Public. Click "Create repository".
3. On the next page click "uploading an existing file". Drag index.html from this folder in. Click "Commit changes".
4. Go to vercel.com > "Sign up" > "Continue with GitHub".
5. Click "Add New..." > "Project". Pick the "portfolio" repository > "Import".
6. Leave every setting as it is. Click "Deploy".
7. You get a link like portfolio-xxxx.vercel.app. To change it: Project > Settings > Domains > edit to somayvaidh.vercel.app (if free).

Updating later: replace index.html in the GitHub repository. Vercel republishes on its own within a minute.

Option B - Vercel command line (if Node.js is installed)
1. Open Command Prompt in C:\Vercel_Resume
2. Run:  npx vercel
3. Log in when asked, accept the defaults. Then run:  npx vercel --prod

Where to use the link: LinkedIn Featured section and Contact info, resume header, email signature, outreach messages.
