The Souled Store · Category1.5% → ~3%

Growing a new category in stores

Problem
Perfume was a small share of store sales, and nobody knew whether the gap was the product, the customer or the store.
Approach
Cohort retention over 24 months, split by channel; a SKU migration matrix; cannibalisation between two hero fragrances; cross-category retention; and a Good / Mid / Bad store segmentation by monthly sales share. Compared in-stock days with stock-out days per store to test whether perfume was driving extra sales or just substituting for other purchases.
Outcome
Set a target of one perfume per staff member per day, which lifted perfumes sold per day (PDS) and with it the category's overall contribution. Ran monthly perfume training sessions for store staff and flagged under-performing stores for follow-up. Category share of sales rose from 1.5% to about 3%. Presented to founders and CXOs.
BigQuery · SQL · Python · Google Sheets
The Souled Store · Planning3–4 days → 1 run

Store targets that phase themselves

Problem
Monthly store targets were split into daily targets by hand, which took 3–4 days every month and was easy to get wrong.
Approach
Built a model that phases each store's monthly target into daily targets by state, weighting weekdays, weekends, public holidays and retail events. The output feeds a Looker Studio dashboard where stores track daily achievement against target.
Outcome
A repeatable monthly run instead of days of manual work, and one shared view of targets for stores and Retail Ops.
Python · Google Sheets · Looker Studio

The Souled Store · RiskCXO framework

Spotting returns abuse in stores

Problem
Leadership suspected some customers were abusing in-store returns, but there was no consistent way to tell abuse from normal returns.
Approach
Built user-level and order-level views of offline returns, then a flagging waterfall: low activity, high returner (50%+ return rate with 4+ items), watch list, and volume returner. Added cross-store return tracking, where items are bought in one store and returned in another.
Outcome
A framework presented to the CXO team. Flagged customers were routed to Customer Experience for call-backs.
BigQuery · SQL · Excel
The Souled Store · Diagnosis100% → 43%

Was it demand, or the store?

Problem
A franchise store's conversion fell sharply after an incident, and the question was whether customers had stopped coming or stopped buying.
Approach
Compared footfall like-for-like against last year, then checked conversion, stock and fixture use section by section.
Outcome
Footfall held up, but display use had fallen from 100% to 43% because of fixture damage. The fix was the fixtures, not marketing or staffing.
SQL · footfall camera data · Excel
The Souled Store · Operations80+ stores

Automating the mystery-shopper audit

Problem
Each monthly mystery-shopper round had to be downloaded, reformatted and pasted into a scoring workbook by hand, and the vendor's format kept changing.
Approach
Pulled each round straight from the audit vendor's API and mapped it to a fixed 23-question scorecard (first impression, assistance, trial room, cross-selling, checkout), reconciling questions the vendor had split or reworded.
Outcome
One command per round, with store scorecards that always show the last three rounds.
Python · REST API · Excel
